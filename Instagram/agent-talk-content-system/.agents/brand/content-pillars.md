# Agent Talk — Content Pillars & Programming Strategy

Agent Talk structures all video production and social distribution around 4 core content pillars. Every video produced must clearly belong to one primary pillar and support adjacent ones.

---

## Pillar 1: "The Autonomous Pair Programmer" (Developer Experience & Tools)
- **Focus:** Practical, hands-on developer tooling, CLI agents, IDE extensions, open-source repos, and terminal workflows.
- **Example Topics:**
  - T3 Code: streaming terminal diffs to your phone.
  - Claude Code vs. Cursor: when to use CLI vs. GUI agents.
  - Setting up Model Context Protocol (MCP) servers locally.
  - Local LLM coding benchmarks using Ollama & Qwen 2.5 Coder.
- **Primary Goal:** High Save rate & practical utility. Developers bookmark these to install or test on their laptops later.

---

## Pillar 2: "Production Incidents & Chaos" (Dev Humor & Relatability)
- **Focus:** The comedic, stressful, and chaotic realities of giving autonomous agents write-access to git repos.
- **Example Topics:**
  - When an AI agent decides to refactor your entire auth router at midnight.
  - "I asked for a CSS fix and it rewritten the backend in Rust."
  - Merging PRs from your phone during dinner and praying CI passes.
  - Infinite token loops and hallucinated npm packages.
- **Primary Goal:** High Share rate ("Sends"). Developers tag their coworkers and share to engineering Slack/Discord channels.

---

## Pillar 3: "Agent Architecture & Under the Hood" (Technical Intelligence)
- **Focus:** How autonomous agents actually think, plan, call tools, and interact with operating systems.
- **Example Topics:**
  - How AST (Abstract Syntax Tree) diffing works in modern coding agents.
  - Sandboxing agents with Docker containers to prevent accidental `rm -rf`.
  - Context compaction: how agents remember large codebases across hours.
  - Bring-Your-Own-Server (BYOS) architectures and end-to-end encryption.
- **Primary Goal:** Search discovery & Technical credibility. Establishes `@agent.talk` as an authoritative voice rather than a shallow aggregator.

---

## Pillar 4: "The Future of Building" (Culture & Industry Shifts)
- **Focus:** How the role of the software engineer is evolving from typing syntax to directing systems.
- **Example Topics:**
  - The shift from writing code to reviewing agent output.
  - Why terminal-based agents are winning over web chat interfaces.
  - How solo developers are building multi-service platforms using autonomous swarms.
- **Primary Goal:** Comments & Community Discussion. Triggers debate on architecture, ethics, and developer identity.
