# Agent Talk — Social Media Pre-Flight Posting Checklist

Run this checklist before scheduling or posting any Reel, Short, or TikTok.

---

## 1. Video & Asset Verification
- [ ] Aspect ratio is strictly 9:16 vertical (1080 × 1920).
- [ ] Key visual elements (character faces, subtitles, phone screen) are inside Instagram safe zones (clear of header, right action rail, and lower caption area).
- [ ] Subtitles are burned in, highly legible, centered, and synchronized to within 50ms of audio.
- [ ] Audio loudness is normalized between -14 LUFS and -16 LUFS (no clipping, clear dialogue above background music).
- [ ] No watermarks or foreign platform logos.

---

## 2. Copy & Metadata Verification
- [ ] First sentence of caption contains primary keyword or curiosity hook before the "...more" fold (first 80–125 characters).
- [ ] Brand voice check: Sounds conversational, technically accurate, and natural (no generic hype, no fake stats).
- [ ] Emoji count is between 1 and 4, placed functionally.
- [ ] Exactly one clear Call to Action (CTA) included.
- [ ] Hashtags are vetted: 5–10 highly relevant niche and community tags; no spam tags (#viral, #fyp).
- [ ] Reel Cover image selected: clean high-res frame with high-contrast text overlay readable in grid view.
- [ ] Accessibility Alt Text prepared and pasted into advanced settings.

---

## 3. Platform Distribution
- [ ] **Instagram Reels:**
  - [ ] Recommended caption pasted.
  - [ ] Pinned comment drafted and ready to post immediately after upload.
  - [ ] Topic tags selected in Instagram settings (e.g. Technology, Software).
  - [ ] Share to Feed toggled ON.
- [ ] **YouTube Shorts:**
  - [ ] Short-form search title optimized (under 60 characters).
  - [ ] Description populated with keywords, repo credits, and `#Shorts`.
  - [ ] Pinned comment posted.
- [ ] **TikTok:**
  - [ ] TikTok-native caption with search terms and relevant sound.

---

## 4. Post-Publishing Protocol (First 60 Minutes)
- [ ] Post pinned comment immediately.
- [ ] Share Reel to Instagram Stories with interactive sticker (poll or slider) to drive initial session engagement.
- [ ] Reply to the first 5–10 comments within 30 minutes with conversational, thoughtful responses to spark comment threads.
- [ ] Check analytics at 24 hours and 7 days; log metrics in `analytics/performance-reports/`.
