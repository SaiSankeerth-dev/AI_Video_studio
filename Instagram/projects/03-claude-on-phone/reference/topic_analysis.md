---

## 1. Core Source Extraction

| Source Dimension | Extracted Facts & Data |
|---|---|
| **Central Premise** | Developers can now monitor, interact with, and approve changes from their AI coding agents directly from their smartphone for free. |
| **Featured Software** | **T3 Code** (`t3code`), created by Theo Browne and the T3 OSS community. |
| **Open Source Credentials** | 52,000+ GitHub stars, MIT licensed, 100% free with zero markup. |
| **Supported Agents** | Claude Code, Codex, Cursor, Grok, OpenCode, and Google Antigravity. |
| **Pricing / Business Model** | "Bring Your Own Subscription" (BYOS). Official FAQ: *"There's no way to pay us to use T3 Code."* It uses existing user API keys and accounts. |
| **Architecture / Mechanism** | The heavy agent execution and compilation run locally on the developer's computer (Mac/Windows/Linux). The mobile app (iOS/Android) connects securely to view diffs, reply to agent prompts, and tap "Approve & Merge". |
| **Setup Process** | Single command installation (`curl -fsSL https://t3.codes/install.sh | sh`), run `t3`, and authenticate. |

## 2. Agent Talk Video Narrative Strategy

### Hook (0:00–0:05)
- **Visual:** Claude stands proudly on a sleek glass smartphone lying on a dark wooden studio desk. Antenna glowing golden-amber.

- **Problem:** AI coding agents like Claude Code, Codex, and Antigravity do incredible multi-file work, but leaving your laptop means pausing the workflow or coming back to stuck terminal prompts.
- **Solution:** Introduce **T3 Code** — an open-source hub that connects your desktop agents directly to your phone.
- **Visual:** Floating 3D holographic badges of supported agents (Claude Code, Cursor, Codex, Google Antigravity) spinning into an unified interface.

### How It Works — The "Couch Approval" Flow (0:14–0:24)
